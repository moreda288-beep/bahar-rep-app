# بهار — تطبيق المندوب

نسخة تجريبية من تطبيق مندوب شركة التوابل والنكهات: التجار، الطلبيات بالأصناف والأسعار، التحصيل كاش وآجل ودفعات، صور الإيصالات، وأداء المندوب.

- تطبيق ويب في ملف واحد (`index.html`) من غير أي مكتبات.
- بيتثبت على الموبايل من «إضافة للشاشة الرئيسية».
- البيانات في النسخة دي بتتحفظ على الجهاز نفسه بس.
- لوحة التحكم (القفل، التحديثات، أكواد التفعيل) محتاجة قاعدة بيانات، وهتتربط في النسخة الجاية.
